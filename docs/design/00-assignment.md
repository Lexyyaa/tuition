### 백엔드 과제: 학원 원비 고지 시스템

### 개요

학원 원장이 강좌와 수강생을 관리하고, 매달 학부모에게 원비 고지서를 알림톡으로 발송하며, 납부를 관리하는 서비스의 백엔드를 구현합니다.

- 제한 시간 5시간, AI 도구 사용 자유
- 학원 3,000곳, 수강 등록 50만 건 규모
- 애플리케이션 인스턴스 2대 이상으로 운영

필수 요구사항을 모두 구현하기 어려운 분량입니다. 구현 범위와 우선순위도 평가에 포함됩니다.

### 기술 조건

- Java 17 이상, Spring Boot 3.x, Spring Data JPA, MySQL
- Docker Compose로 실행 가능
- 인증 미구현. 요청 헤더로 학원을 식별하며 다른 학원 데이터 접근은 거부
- REST API로 설계하고 API 명세를 README 또는 별도 문서에 기재
- 요구사항 중 정의가 필요한 부분은 직접 가정하고 README에 근거를 기재

### 외부 연동

```java
public interface KakaoClient {
    SendAccepted send(String messageId, String phone, String templateCode, Map<String, String> vars);
}
public interface SmsClient {
    SendAccepted send(String messageId, String phone, String text);
}
```

- 알림톡 공급사 제한: 초당 100건, 초과 시 429. 응답 지연 50~300ms
- 발송 결과는 공급사가 웹훅으로 비동기 전달. 결과 코드: `DELIVERED`, `FAILED_NOT_KAKAO_USER`, `FAILED_ETC`
- 가짜 구현체를 작성하고 지연·실패 비율을 설정값으로 조절 가능해야 함

### 필수 요구사항

#### 1. 강좌와 수강

- 강좌 등록: 강좌명, 월 원비, 수업 요일(복수), 정원
- 수강 등록: 강좌, 수강생, 시작일, 종료일(선택), 납부일(1~31)
- 수강 종료: 종료일 지정
- 정원 초과 등록 불가
- 같은 수강생의 같은 강좌 기간 중복 등록 불가

#### 월 원비

- 시작 월과 종료 월은 해당 월 수업일 중 수강 기간에 포함된 날의 비율로 산정, 원 미만 절사
  - 예: 월 원비 300,000원, 월·수·금, 2026-03-11 시작 → 207,692원
- 형제 할인 적용. 할인율과 기준은 직접 정의
- 원장이 특정 수강 등록의 특정 월 금액을 수정 가능
- 납부기한은 납부일 기준

#### 고지서 생성

- 월을 지정해 해당 월 유효 수강 등록 전체에 고지서를 생성하는 작업
- 매월 1일 09:00 자동 생성 및 발송 시작
- 50만 건 생성 소요 시간을 README에 기재

#### 발송

- 인스턴스 2대 이상에서 동일 고지서 중복 발송 없음
- 인스턴스 합산 초당 100건 이하 유지
- 21:00~08:00 발송 금지
- 수신 거부 학부모 제외

#### 발송 결과

- 웹훅으로 발송 상태 확정
- `FAILED_NOT_KAKAO_USER`는 SMS 대체 발송 (유료 플랜 학원만)
- 발송 후 15분 내 웹훅 미수신 시 미확정 처리
- 발송 채널은 추후 추가 예정

#### 납부

- 고지서에 대한 납부 처리. 부분 납부 허용. 상태: `UNPAID`, `PARTIAL`, `PAID`
- 납부 요청의 멱등성 보장
- 납부기한 경과 3일, 7일 시점에 미납 안내 발송
- 기준일 시점 미납 고지서 목록 조회, 연체일수 내림차순

#### 운영

- 발송 작업 진행 현황 조회: 상태별 건수와 초당 처리량. 50만 건 규모에서 1초 이내 응답
- 발송 작업의 실패 건 조회, 사유별 필터
- 고지서 단건 이력 조회. 로그로도 동일 추적이 가능해야 함
- 실패 건 재발송

### 선택

- 학원별 발송 시각 설정 (08~20시, 정시 단위)

### 검증 요구

- 정원 동시 등록 테스트
- 원비 산정 파라미터 테스트
- 고지서 5만 건, 인스턴스 2대 실행 결과 (소요 시간, 중복 여부, 초당 요청 수)
- 실행 중 인스턴스 1대 종료 시 결과
- 주요 쿼리 실행 계획과 인덱스 설계 근거
